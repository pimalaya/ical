## MODIFIED Requirements

### Requirement: A parameter that says what the value means contests it
In merge, replacing "Retyping a value contests it". A change to `VALUE`, `TZID`, `ENCODING`, `CHARSET`, `LANGUAGE`, `FMTTYPE`, `RANGE`, `RELATED`, `FBTYPE`, `RELTYPE` or `LINKREL` collides with a value-level action on the other side, both ways; a parameter describing the thing a value names still merges beside it.
