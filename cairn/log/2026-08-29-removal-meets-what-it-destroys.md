# A removal meets everything it takes away

A whole-property removal now collides with a change to that property's value, parameters and list items, and a component removal collides with every non-removal action nested under it at any depth. Two removals overlapping still pass each other by, since both sides agreed the data goes.

Which side is the one removing is settled by granularity rather than by the word: a side that drops one parameter keeps the property, so against a side that removed the property whole it is the one preserving data and its line survives.

An attendee accepting an invitation while the other side drops the attendee line, and a reminder added to an event the other side deleted, are both reported now instead of disappearing in silence.
